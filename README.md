# Surplus Intelligence-inspired React frontend

Independent React + Vite concept, not affiliated with Surplus Intelligence. Marketplace prices, statistics, and playground output are demo data.

## Run locally
1. Install Node.js LTS.
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the URL Vite prints, normally http://localhost:5173

Build with `npm run build`. Live model inference, authentication, payments, live prices, and seller onboarding require backend services. Never expose secret API keys in frontend code.
